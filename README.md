# Django Portfolio (Learning Project)

This is my first Django project, built while learning web development 
step by step. I have a background in textile & print design, and I'm 
now learning to code with the goal of working as a web developer.

## What this project includes
- Django URLs, Views, Templates (with template inheritance)
- Models & database (SQLite), Django Admin
- Dynamic URLs for blog posts and portfolio items
- Forms (including Django's ModelForm) with validation
- Basic authentication (login/logout)

## Note
This project's code structure is still a work in progress as I continue 
learning — I'm sharing it to document my learning journey.
